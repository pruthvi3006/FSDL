# FSDL Assignments

This repository contains a collection of web development assignments and mini projects completed as part of the FSDL coursework. The projects span static webpages, interactive front-end pages, and full-stack applications built with Node.js, Express, and MongoDB.

## Repository Structure

- `Assignment 1/` – Basic HTML task
- `Assignment 2/` – Portfolio-style webpage
- `Assignment 3/` – Product or shopping landing page
- `Assignment 4/` – Front-end UI assignment
- `Assignment-5/` – Node.js/Express project with MVC structure
- `Assignment-6/` – Second-hand marketplace / e-commerce portal
- `Assignment 7/` – Full-stack review system with client and server apps

## Project Highlights

- Front-end development with HTML, CSS, and JavaScript
- Responsive and visually styled web pages
- Server-side applications using Express.js
- Data persistence with MongoDB and Mongoose
- API-based architecture for client-server communication
- Assignment-specific README files in several project folders

## Getting Started

1. Open any assignment folder in this repository.
2. Read that folder's local README or project instructions, if available.
3. Install dependencies for the relevant project:

   ```bash
   npm install
   ```

4. Run the app using the project-specific script, for example:

   ```bash
   npm start
   ```

   or

   ```bash
   npm run dev
   ```

## Notes

- Some folders are static HTML/CSS projects and can be opened directly in a browser.
- Full-stack assignments may require a MongoDB instance and environment variables.
- For the most up-to-date instructions, check each assignment's own README file.

## Purpose

This repository is intended for academic and learning purposes, showcasing practical web development work across multiple assignments and application types.
